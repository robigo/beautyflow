# פיילוט מבודד מהאייפון

הפיילוט מריץ את הממשק וה־API באותה כתובת, מול PostgreSQL 16 זמני בשם `beautyflow_ci`. הוא אינו משתמש ב־Supabase או ב־API הפעיל ב־Vercel. הנתונים נשמרים רק כל עוד מכולת מסד הנתונים פועלת, ונמחקים בעצירתה.

## פתיחה ב־Codespaces

1. במאגר GitHub, בחרו את הענף שמכיל את התצורה. לחצו **Code → Codespaces → New with options**.
2. ב־**Dev container configuration** בחרו **BeautyFlow isolated pilot** (`.devcontainer/pilot/devcontainer.json`).
3. צרו את ה־Codespace. התקנת התלויות מתבצעת אוטומטית, ואחריה עולה שרת הפיילוט בפורט **8080**.
4. בלשונית **Ports**, השאירו את פורט 8080 כ־**Private**. העתיקו את הכתובת שלו ופתחו באייפון, כאשר אתם מחוברים לאותו חשבון GitHub.

יש להופיע פס צהוב עם הכיתוב **סביבת בדיקה בלבד — נתונים זמניים**. פרטי חשבון הבדיקה מוזנים אוטומטית בטופס:

- אימייל: `pilot-owner@example.test`
- סיסמה: `pilot-only-password-2026`

העסק **פיילוט מבודד** כולל חדר בדיקה ושירות בשם **טיפול בדיקה**, במחיר 120. אין להזין פרטי לקוחות אמיתיים.

## בדיקה מהטלפון

1. התחברו ופתחו את העסק **פיילוט מבודד**.
2. בחרו **קביעת תור** בתפריט הנייד. הזינו שם וטלפון בדויים, שירות **טיפול בדיקה**, מחיר **135**, ותאריך עתידי.
3. שמרו, וודאו שמוצג 135 ביומן. רעננו את הדף, בחרו שוב יומן, וודאו שהמחיר נשאר.
4. העתיקו את קישור הלקוח מהעסק, ופתחו אותו בחלון נפרד. הוא חייב להיות באותו דומיין `app.github.dev`. המחיר הציבורי הוא מחיר השירות: 120.

## תקלות והפעלה מחדש

לוג ההפעלה נמצא ב־`/tmp/beautyflow-pilot.log`. אם השרת אינו פועל, הריצו בטרמינל:

```sh
node server/test/pilot-workspace.mjs
```

הסקריפט מסרב למסד נתונים שאינו `127.0.0.1/beautyflow_ci` או שאינו PostgreSQL 16, לפני הרצת המיגרציות. הוא יוצר סוד JWT זמני וחשבון בדיקה בלבד. עצירה והפעלה מחדש של השרת בלבד מבטלות אסימוני התחברות קודמים; ניתן להתחבר שוב לחשבון הבדיקה.

יש לעצור את ה־Codespace בסיום. מכולת מסד הנתונים משתמשת ב־tmpfs ללא volume קבוע, ולא מפורסם פורט למסד הנתונים. התצורה הקיימת של הפיתוח, ה־HTML המפורסם, הגדרות Vercel והמיגרציות עצמן נשארים ללא שינוי.

הבדיקות האוטומטיות מפעילות את אותו שרת פיילוט, בודקות כניסה ושמירת מחיר במסך בגודל טלפון, ומוודאות שחיבור חיצוני נחסם על ידי מדיניות הדפדפן `connect-src 'self'`.
